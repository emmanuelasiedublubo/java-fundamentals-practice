# Object-Oriented Programming

This module contains Java programs that demonstrate the fundamental principles of object-oriented programming, including classes, objects, constructors, encapsulation, inheritance, polymorphism, abstraction, and interfaces.

## Concepts Covered

- Classes and objects
- Object attributes
- Creating multiple objects
- Constructors
- The `this` keyword
- Encapsulation
- Getters and setters
- Inheritance
- Method overriding
- Polymorphism
- Abstract classes and methods
- Interfaces
- Reusable object-oriented design

---

## Programs

| Program | Description |
|---------|-------------|
| StudentObject | Demonstrates creating a class, defining attributes, and creating an object. |
| CarObject | Demonstrates creating multiple objects from the same class. |
| ConstructorExample | Demonstrates using a constructor to initialize object attributes. |
| EncapsulationExample | Demonstrates private fields with getter and setter methods. |
| InheritanceExample | Demonstrates inheritance between parent and child classes. |
| MethodOverriding | Demonstrates overriding an inherited method. |
| PolymorphismExample | Demonstrates polymorphism using parent references and child objects. |
| AbstractClassExample | Demonstrates abstract classes and abstract methods. |
| InterfaceExample | Demonstrates implementing an interface. |
| BankAccount | Combines constructors, encapsulation, methods, and validation in a simple application. |
