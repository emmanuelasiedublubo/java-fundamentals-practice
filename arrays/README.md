# Arrays

This module contains Java programs that demonstrate how arrays can be used to store, access, search, analyze, and manipulate collections of values.

## Concepts Covered

- Array declaration and initialization
- Accessing array elements
- Traversing arrays with loops
- Calculating sums and averages
- Finding minimum and maximum values
- Searching for elements
- Reversing array output
- Copying arrays
- Counting values based on conditions
- Finding the second largest value

---

## Programs

| Program | Description |
|---------|-------------|
| PrintArray | Prints all elements in an integer array. |
| SumArray | Calculates the sum of all array elements. |
| AverageArray | Calculates the average of array elements. |
| MaximumArray | Finds the largest value in an array. |
| MinimumArray | Finds the smallest value in an array. |
| SearchElement | Searches for a specific value in an array. |
| ReverseArray | Prints array elements in reverse order. |
| CopyArray | Copies elements from one array into another. |
| CountEvenOdd | Counts even and odd values in an array. |
| SecondLargest | Finds the second largest value in an array. |
