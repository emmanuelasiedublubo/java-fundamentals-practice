# Switch Statements

This module contains Java programs that demonstrate how switch statements can be used to select and execute different blocks of code based on a value.

## Concepts Covered

- `switch`
- `case`
- `break`
- `default`
- Switching with integers
- Switching with characters
- Switching with strings
- Multiple cases sharing the same action
- Combining switch statements with conditionals

---

## Programs

| Program | Description |
|---------|-------------|
| DayOfWeekSwitch | Displays a day of the week based on a numeric value. |
| MonthSwitch | Displays a month based on a numeric value. |
| GradeSwitch | Displays a message based on a letter grade. |
| SimpleCalculatorSwitch | Performs basic arithmetic operations using a switch statement. |
| TrafficLightSwitch | Displays an action based on a traffic light color. |
| SeasonSwitch | Displays a season based on a month number. |
| MenuOptionSwitch | Performs an action based on a selected menu option. |
| NumberToWordSwitch | Converts a number from 1 to 5 into its word equivalent. |
| VowelSwitch | Determines whether a character is a vowel or consonant. |
| LanguageSwitch | Displays a greeting based on a selected language. |
