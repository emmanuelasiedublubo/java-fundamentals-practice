# Collections

This module contains Java programs that demonstrate how the Java Collections Framework can be used to store, organize, search, sort, and process groups of data.

## Concepts Covered

- ArrayList
- LinkedList
- HashSet
- TreeSet
- HashMap
- Enhanced for loops
- Searching collections
- Sorting collections
- Removing elements
- Key-value pairs
- Iterating through maps

---

## Programs

| Program | Description |
|---------|-------------|
| ArrayListExample | Demonstrates creating, adding to, and accessing an ArrayList. |
| LinkedListExample | Demonstrates storing and accessing elements in a LinkedList. |
| HashSetExample | Demonstrates storing unique elements in a HashSet. |
| TreeSetExample | Demonstrates storing unique elements in sorted order. |
| HashMapExample | Demonstrates storing data using key-value pairs. |
| IterateCollection | Demonstrates iterating through an ArrayList. |
| SortArrayList | Demonstrates sorting an ArrayList. |
| SearchArrayList | Demonstrates searching for an element in an ArrayList. |
| RemoveCollectionElement | Demonstrates removing an element from an ArrayList. |
| StudentGradeManager | Uses a HashMap to store student scores and calculate grades. |

## Skills Developed

After completing this module, I was able to:

- Work with common Java collection types.
- Understand the differences between lists, sets, and maps.
- Store and retrieve dynamic groups of data.
- Search, sort, and remove collection elements.
- Iterate through collections using enhanced for loops.
- Work with key-value pairs using HashMap.
