# File Handling

This module contains Java programs that demonstrate how to create, write, read, append, copy, inspect, and delete files using Java.

## Concepts Covered

- Creating files
- Writing data to files
- Reading data from files
- Appending data to existing files
- Deleting files
- Retrieving file information
- Writing multiple lines
- Reading multiple lines
- Copying file contents
- File handling with exception handling
- FileWriter
- File
- Scanner

---

## Programs

| Program | Description |
|---------|-------------|
| CreateFileExample | Demonstrates how to create a new file. |
| WriteFileExample | Demonstrates how to write text to a file. |
| ReadFileExample | Demonstrates how to read text from a file. |
| AppendFileExample | Demonstrates how to append text to an existing file. |
| DeleteFileExample | Demonstrates how to delete a file. |
| FileInformationExample | Demonstrates how to retrieve information about a file. |
| WriteMultipleLines | Demonstrates how to write multiple lines to a file. |
| ReadMultipleLines | Demonstrates how to read multiple lines from a file. |
| CopyFileExample | Demonstrates how to copy contents from one file to another. |
| StudentRecordFile | Demonstrates writing and reading student information using a file. |
