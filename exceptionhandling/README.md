# Exception Handling

This module contains Java programs that demonstrate how exceptions can be detected, handled, and managed to prevent unexpected program termination.

## Concepts Covered

- `try` and `catch`
- Arithmetic exceptions
- Array index exceptions
- Number format exceptions
- Multiple catch blocks
- `finally`
- `throw`
- `throws`
- Custom exceptions
- Exception messages
- Combining exception handling with object-oriented programming

---

## Programs

| Program | Description |
|---------|-------------|
| BasicTryCatch | Demonstrates basic exception handling using try and catch. |
| DivideByZeroException | Handles division by zero using ArithmeticException. |
| ArrayIndexException | Handles attempts to access an invalid array index. |
| NumberFormatExceptionExample | Handles invalid String-to-integer conversion. |
| MultipleCatchExample | Demonstrates multiple catch blocks for different exceptions. |
| FinallyExample | Demonstrates the use of the finally block. |
| ThrowExample | Demonstrates manually throwing an exception. |
| ThrowsExample | Demonstrates declaring an exception using throws. |
| CustomExceptionExample | Demonstrates creating and using a custom exception. |
| BankWithdrawalException | Uses a custom exception to handle insufficient account funds. |
