# Variables and Constants

This module contains beginner Java programs that introduce the fundamental concepts of variables, constants, data types, arithmetic operations, and console output.

## Concepts Covered

- Variable declaration
- Variable initialization
- Constants (`final`)
- Integer and decimal data types
- Arithmetic operators
- Mathematical calculations
- Console output

---

## Programs

| Program | Description |
|---------|-------------|
| AreaCalculator | Calculates the area of a rectangle. |
| AverageCalculator | Calculates the average of three numbers. |
| PerimeterCalculator | Calculates the perimeter of a rectangle. |
| SimpleInterestCalculator | Calculates simple interest. |
| TemperatureConverter | Converts temperature between Celsius and Fahrenheit. |
| VolumeCalculator | Calculates the volume of a rectangular prism. |
