# Loops

This module contains Java programs that demonstrate repetition and iteration using `for` and `while` loops.

## Concepts Covered

- `for` loops
- `while` loops
- Loop counters
- Increment and decrement operations
- Repeated calculations
- Number sequences
- Accumulation using variables
- Basic algorithmic repetition

---

## Programs

| Program | Description |
|---------|-------------|
| PrintNumbers1To10 | Prints the numbers from 1 to 10. |
| PrintNumbers10To1 | Prints the numbers from 10 down to 1. |
| PrintEvenNumbers | Prints even numbers from 2 to 20. |
| PrintOddNumbers | Prints odd numbers from 1 to 19. |
| SumOfNumbers | Calculates the sum of numbers from 1 to 10. |
| MultiplicationTable | Displays the multiplication table for a given number. |
| FactorialCalculator | Calculates the factorial of a number. |
| ReverseNumber | Reverses the digits of an integer. |
| CountDigits | Counts the number of digits in an integer. |
| FibonacciSeries | Prints the first 10 numbers in the Fibonacci sequence. |
