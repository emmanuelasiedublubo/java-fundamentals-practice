# Conditionals

This module contains Java programs that demonstrate decision-making using conditional statements and logical expressions.

## Concepts Covered

- `if`
- `if...else`
- `else if`
- Comparison operators
- Logical operators
- Modulus operator
- Nested conditions
- Multiple-condition decision making

---

## Programs

| Program | Description |
|---------|-------------|
| PassFailChecker | Determines whether a student passes or fails based on an exam score. |
| PositiveNegativeChecker | Determines whether a number is positive, negative, or zero. |
| EvenOddChecker | Determines whether a number is even or odd. |
| LargestNumberChecker | Finds the largest of three numbers. |
| SmallestNumberChecker | Finds the smallest of three numbers. |
| GradeChecker | Assigns a grade based on a student's score. |
| VotingEligibilityChecker | Determines whether a person is eligible to vote based on age. |
| LeapYearChecker | Determines whether a given year is a leap year. |
| VowelConsonantChecker | Determines whether a character is a vowel or consonant. |
| DayOfWeekChecker | Displays the day of the week based on a number. |
| MonthChecker | Displays the month name based on a number. |
| DivisibilityChecker | Checks whether a number is divisible by 3 and/or 5. |
| CharacterTypeChecker | Determines whether a character is a letter, digit, or special character. |
| SimpleCalculator | Performs basic arithmetic operations using conditional statements. |
| TemperatureCategoryChecker | Classifies a temperature as cold, warm, or hot. |
