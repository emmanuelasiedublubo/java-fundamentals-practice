# Methods

This module contains Java programs that demonstrate how methods can be used to organize code into reusable and manageable blocks.

## Concepts Covered

- Creating and calling methods
- Method parameters
- Passing arguments
- Return values
- `void` methods
- Methods with different return types
- Combining methods with conditionals
- Combining methods with loops
- Method overloading
- Reusable arithmetic methods

---

## Programs

| Program | Description |
|---------|-------------|
| SimpleMethod | Demonstrates how to create and call a simple method. |
| GreetingMethod | Demonstrates passing an argument to a method using a parameter. |
| AddNumbersMethod | Adds two numbers using a method and returns the result. |
| MaximumMethod | Uses a method to determine the larger of two numbers. |
| EvenOddMethod | Uses a method to determine whether a number is even or odd. |
| SquareMethod | Calculates and returns the square of a number. |
| FactorialMethod | Calculates and returns the factorial of a number. |
| MethodWithReturn | Demonstrates a method that returns a String value. |
| MethodOverloading | Demonstrates methods with the same name but different parameters. |
| CalculatorMethods | Uses multiple reusable methods to perform basic arithmetic operations. |
